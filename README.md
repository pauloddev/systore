# SY STORE — Landing page

Site estático (HTML, CSS e JS num único `index.html`), sem build.

- `img/` — logo, fotos dos looks, fachadas, `og.jpg` (capa de prévia do link)
- `video/` — vídeos do carrossel (MP4 sem áudio) e capas `.webp`
- `fonts/` — Cormorant Garamond e Manrope (locais)

Para publicar: Netlify, Vercel ou GitHub Pages apontando para a raiz do repositório.
Depois de definir o domínio, troque `og:image` e `og:url` no `<head>` pelo endereço completo (ex.: `https://seudominio.com/img/og.jpg`) para a prévia aparecer no WhatsApp.
